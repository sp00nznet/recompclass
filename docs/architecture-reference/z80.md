# Zilog Z80 Quick Reference

## Overview

The Z80 is an 8-bit CPU introduced in 1976 as a superset of the Intel 8080. It
powers the ZX Spectrum, MSX, Amstrad CPC, Sega Master System and Game Gear, the
TI-83/84 calculators, and the Game Boy's audio-adjacent cousins -- and, in
heavily modified form, inspired the Game Boy's own SM83.

- Clock: 3.5 MHz (ZX Spectrum), 3.58 MHz (MSX, Master System), 4 MHz (many
  arcade boards), 6 or 15 MHz (TI-83+ / TI-84+)
- 8-bit data bus, 16-bit address bus (64 KB addressable)
- A **separate 16-bit I/O address space**, reached only by `IN` and `OUT`

The Z80 has no fixed memory map. Each system defines its own, so "the Z80
memory map" is a question about the machine, not the CPU. See
[System Memory Maps](#system-memory-maps) below.

## Registers

| Register | Width  | Notes                                             |
|----------|--------|---------------------------------------------------|
| A        | 8-bit  | Accumulator                                       |
| F        | 8-bit  | Flags (see below)                                 |
| B, C     | 8-bit  | General purpose / BC pair; B is the `DJNZ` counter |
| D, E     | 8-bit  | General purpose / DE pair                         |
| H, L     | 8-bit  | General purpose / HL pair                         |
| IX, IY   | 16-bit | Index registers, used as `(IX+d)` with signed `d` |
| SP       | 16-bit | Stack pointer                                     |
| PC       | 16-bit | Program counter                                   |
| I        | 8-bit  | Interrupt vector high byte (interrupt mode 2)     |
| R        | 8-bit  | Memory refresh counter; bits 0-6 increment, bit 7 is preserved |

**16-bit pairs:** AF, BC, DE, HL (high byte first)

**Shadow (alternate) set:** A', F', B', C', D', E', H', L'. Not addressable
directly -- you swap banks:

| Instruction | Swaps                       |
|-------------|-----------------------------|
| `EX AF, AF'`| AF with AF'                 |
| `EXX`       | BC, DE, HL with BC', DE', HL' |

**Undocumented halves:** `IXH`, `IXL`, `IYH`, `IYL` address the halves of the
index registers. Unofficial, widely used, and supported by real silicon.

### Flags Register (F)

| Bit | Flag | Name             | Set when...                                        |
|-----|------|------------------|----------------------------------------------------|
| 7   | S    | Sign             | Bit 7 of the result is set (result is negative)     |
| 6   | Z    | Zero             | Result is zero                                      |
| 5   | F5   | (undocumented)   | Copy of bit 5 of the result                         |
| 4   | H    | Half-Carry       | Carry from bit 3 to bit 4                           |
| 3   | F3   | (undocumented)   | Copy of bit 3 of the result                         |
| 2   | P/V  | Parity/Overflow  | **Parity** after logic ops, **signed overflow** after arithmetic |
| 1   | N    | Add/Subtract     | Last operation was a subtraction; only `DAA` reads it |
| 0   | C    | Carry            | Carry out of bit 7 / borrow                         |

`P/V` carrying two unrelated meanings depending on the instruction is the
single most common source of Z80 flag bugs. `F3` and `F5` are undocumented but
observable, and some software -- particularly ZX Spectrum demos -- depends on
them.

## Addressing Modes

| Mode                  | Syntax      | Example            |
|-----------------------|-------------|--------------------|
| Immediate 8-bit       | n           | `LD A, $42`        |
| Immediate 16-bit      | nn          | `LD BC, $1234`     |
| Register              | r           | `LD A, B`          |
| Register indirect     | (HL)        | `LD A, (HL)`       |
| Register indirect     | (BC), (DE)  | `LD A, (BC)`       |
| Extended (absolute)   | (nn)        | `LD A, ($8000)`    |
| Indexed               | (IX+d)      | `LD A, (IX+$05)`   |
| Indexed               | (IY+d)      | `LD A, (IY-$02)`   |
| Relative              | e           | `JR NZ, $-4`       |
| Modified page zero    | p           | `RST $28`          |
| Bit addressing        | b, r        | `BIT 7, (HL)`      |
| I/O immediate         | (n)         | `OUT ($FE), A`     |
| I/O register          | (C)         | `IN A, (C)`        |

The displacement `d` in `(IX+d)` is **signed**, range -128 to +127.

## Opcode Prefixes

| Prefix   | Selects                                              |
|----------|------------------------------------------------------|
| (none)   | Base 8080-compatible set plus Z80 additions          |
| `CB`     | Rotates, shifts, `BIT`/`SET`/`RES`                   |
| `DD`     | Rewrites HL as IX in the instruction that follows    |
| `FD`     | Rewrites HL as IY in the instruction that follows    |
| `ED`     | Extended: block ops, `NEG`, `IM`, `RETI`/`RETN`, 16-bit `ADC`/`SBC` |
| `DD CB`  | Indexed bit ops -- **displacement byte comes before the opcode** |
| `FD CB`  | Same, with IY                                        |

`DD CB d op` is the encoding that breaks naive decoders: the byte order is
prefix, prefix, *displacement*, then opcode. Everywhere else the operand
follows the opcode.

## Key Instructions

| Category     | Instructions                                    | Notes                                    |
|--------------|-------------------------------------------------|------------------------------------------|
| Load         | LD, PUSH, POP, EX, EXX                          | `EX`/`EXX` reach the shadow set          |
| Block move   | LDI, LDIR, LDD, LDDR                            | HL -> DE, BC counts down                 |
| Block search | CPI, CPIR, CPD, CPDR                            | Compare against A, BC counts down        |
| Block I/O    | INI, INIR, IND, INDR, OUTI, OTIR, OUTD, OTDR    | B counts down                            |
| Arithmetic   | ADD, ADC, SUB, SBC, INC, DEC, NEG               | 16-bit ADC/SBC are `ED`-prefixed         |
| Logic        | AND, OR, XOR, CP                                | Set P/V as **parity**                    |
| Rotate/Shift | RLCA, RRCA, RLA, RRA, RLC, RRC, RL, RR, SLA, SRA, SRL, RLD, RRD | `RLD`/`RRD` are BCD nibble rotates |
| Bit ops      | BIT, SET, RES                                   | `CB`-prefixed                            |
| Control      | JP, JR, DJNZ, CALL, RET, RETI, RETN, RST        | Conditions: Z, NZ, C, NC, PO, PE, P, M   |
| Interrupts   | DI, EI, IM 0, IM 1, IM 2                        | `EI` takes effect *after* the next instruction |
| Misc         | NOP, HALT, DAA, CPL, CCF, SCF                   |                                          |

**Conditions** are richer than the SM83's: `PO`/`PE` test parity/overflow and
`P`/`M` test sign, in addition to the familiar `Z`/`NZ`/`C`/`NC`.

## Interrupt Modes

| Mode  | Behaviour                                                                  |
|-------|----------------------------------------------------------------------------|
| IM 0  | The device places an instruction on the bus; in practice always an `RST`    |
| IM 1  | Fixed jump to `$0038`                                                       |
| IM 2  | Vector table: address is `I` (high byte) + byte supplied by the device (low) |

**NMI** is separate, non-maskable, and always vectors to `$0066`. It returns
with `RETN`, which restores the pre-interrupt enable state.

## System Memory Maps

The CPU imposes none of this; each machine does.

**ZX Spectrum 48K**

| Range         | Description                              |
|---------------|------------------------------------------|
| $0000 - $3FFF | ROM (16 KB)                              |
| $4000 - $57FF | Screen bitmap                            |
| $5800 - $5AFF | Screen attributes                        |
| $5B00 - $FFFF | User RAM                                 |

Contended memory: the ULA stalls the CPU when it accesses $4000-$7FFF during
display, so instruction timing depends on *where* the code lives.

**Sega Master System**

| Range         | Description                              |
|---------------|------------------------------------------|
| $0000 - $BFFF | Three paged 16 KB cartridge slots        |
| $C000 - $DFFF | Work RAM (8 KB)                          |
| $E000 - $FFFF | Mirror of work RAM; paging registers at $FFFC-$FFFF |

**TI-83+ / TI-84+**

Flash and RAM are paged into four 16 KB banks. Bank 0 is always the first page
of flash; the rest are selected through port writes.

## Z80 vs SM83 (Game Boy)

The Game Boy CPU is routinely called "a modified Z80". It is not a Z80, and
code written for one will not lift correctly under the other's semantics.

| Feature                    | Z80                          | SM83                              |
|----------------------------|------------------------------|-----------------------------------|
| Shadow registers           | Yes (`EX AF,AF'`, `EXX`)     | None                              |
| IX / IY                    | Yes                          | None                              |
| Flags                      | S Z F5 H F3 P/V N C          | Z N H C only; low nibble always 0 |
| Parity / overflow          | `P/V` flag                   | Not computed at all               |
| Sign flag                  | `S`                          | Not computed                      |
| Block instructions         | `LDIR`, `CPIR`, ...          | None                              |
| Separate I/O space         | Yes (`IN` / `OUT`)           | None -- memory-mapped I/O instead |
| `DJNZ`                     | Yes                          | Removed                           |
| Interrupt modes            | IM 0 / 1 / 2, NMI            | Single fixed table, $0040-$0060   |
| `R` refresh register       | Yes                          | None                              |
| `LD A,(HL+)` / `(HL-)`     | No                           | Yes                               |
| `LDH` / `($FF00+n)` page   | No                           | Yes                               |
| `SWAP` (nibble swap)       | No                           | Yes                               |
| `STOP`                     | No                           | Yes                               |
| `ADD SP,e`, `LD HL,SP+e`   | No                           | Yes                               |
| `RLCA` and friends         | Preserve Z                   | Always clear Z                    |
| Conditions                 | Z NZ C NC PO PE P M          | Z NZ C NC only                    |

**In this course:** Module 8 ("Your First Lift") and Labs 24 and 25 work with a
reduced flag model -- `Z`, `N`, `H`, `C` only. That is the SM83 set, chosen
because the worked example targets Game Boy code and four flags are enough to
learn the mechanics of lifting. A real Z80 lifter needs `S` and `P/V` as well,
and `P/V` has to switch meaning per instruction. Treat those labs as teaching
the *method*, not as a complete Z80 flag implementation.

## Recompiler Pain Points

- **`P/V` has two meanings.** Parity after `AND`/`OR`/`XOR`, signed overflow
  after `ADD`/`SUB`/`ADC`/`SBC`/`NEG`. A lifter that picks one and applies it
  everywhere produces code that is right most of the time, which is the worst
  outcome -- see Module 38 on why "mostly correct" is the hardest bug class.
- **`F3` and `F5` are undocumented but observable.** They are copies of bits 3
  and 5 of the result for most instructions, and follow different rules for
  `BIT n,(HL)`, `CPI`/`CPD`, and `LDI`/`LDD`. Skip them and most software still
  runs; ZX Spectrum demos will not.
- **Shadow registers defeat a naive register model.** If the lifter maps A, B,
  C ... to C locals, `EXX` has to swap eight of them. Two banks plus a
  "which bank is live" selector is the usual answer, and it costs an indirection
  on every register access unless you can prove the bank statically.
- **`DD CB d op` puts the displacement before the opcode.** Decoders written
  around "operands follow the opcode" desynchronise here, and a desynchronised
  decoder produces plausible garbage rather than an error. Module 33's rule
  about treating discovery as a committed artifact applies.
- **Block instructions repeat by rewinding PC.** `LDIR` decrements PC by 2 and
  re-executes, so it is *interruptible mid-transfer*. Lifting it to a tight C
  loop is correct for the data movement and wrong for interrupt latency.
- **`EI` is delayed by one instruction.** Interrupts are not accepted until
  after the instruction following `EI`, which exists so `EI` / `RET` cannot be
  interrupted between them. Idiomatic, and easy to lift incorrectly.
- **The `R` register increments on every M1 cycle.** Some copy protection reads
  it as a cheap entropy source. If you do not model it, the check fails; if you
  model it as a counter without matching the real increment pattern, the check
  fails differently.
- **Separate I/O space.** `IN`/`OUT` do not touch memory. A recompiler that
  routes them through the memory handler will read plausible values from the
  wrong place. Note also that `IN r,(C)` puts B on the high address lines, so
  the "8-bit port number" is really 16 bits on most hardware.
- **`DAA` reads the `N` flag.** It adjusts differently after an add than after
  a subtract, which is why `N` exists at all. It is also the instruction most
  often got wrong -- the Z80 version differs from the SM83 version.
- **Undocumented `SLL` (`SL1`).** Shift left, setting bit 0. Present on real
  silicon, absent from the official documentation, used by some software.
- **Self-modifying code is common.** Z80-era software patches itself routinely.
  Static recompilation assumes code is data you can read once; where that fails,
  Module 49's hybrid approaches are the fallback.
